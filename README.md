# Order Journey Analytics

Discrete event simulation and analytics for order fulfillment journeys using Simio.

## Overview
End-to-end order journey modeling — from order placement through processing, fulfillment, and delivery. Uses Simio for discrete event simulation to identify bottlenecks, optimize throughput, and predict delivery times.

## Stack
- Simio (discrete event simulation)
- Python (data analysis, visualization)
- Pandas, Matplotlib/Plotly (analytics dashboards)
